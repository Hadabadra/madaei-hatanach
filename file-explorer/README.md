# סייר קבצים — תוסף לאוצריא

**מטרה:** לעבוד עם הקבצים שבמחשב בלי לצאת מאוצריא — במיוחד במחשב לימוד נעול, שבו אין גישה לסייר של Windows.

**מה כולל:**
- עיון בכוננים ובתיקיות, חלונית "גישה מהירה", נתיב שאפשר לערוך.
- העתקה, גזירה, הדבקה, מחיקה לסל המיחזור, שינוי שם, תיקייה וקובץ חדשים, מאפיינים.
- חיפוש קבצים זורם, גם בתוכן.
- צפייה פנימית ב-PDF, Word, טקסט ותמונות, או פתיחה ביישום חיצוני — לפי בחירה בהגדרות (⚙).
- כפתור "+ מסמך חדש" בסרגל הקורא.
- עברית ואנגלית; "שליחת הערה" דרך מערכת הדיווח של אוצריא.

**דרישות:** אוצריא 0.9.98 ומעלה. לגישה מלאה — **גשר אוצריא** (OtzariaBridge.exe, בעמוד ה-Releases). בלעדיו התוסף עובד על תיקיות שאישרתם בלבד.
