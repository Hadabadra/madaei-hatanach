# הגדרות מערכת — תוסף לאוצריא

**מטרה:** לשלוט בהגדרות המחשב מתוך אוצריא, ולהפוך את המחשב לעמדת לימוד שבה פתוחה רק אוצריא.

**מה כולל:**
- שמע (עוצמה, השתקה, התקן פלט), בהירות מסך, בלוטות׳, Wi-Fi.
- הפעלה וכיבוי: נעילת מסך, שינה, הפעלה מחדש, כיבוי, ופרטי המחשב.
- מצב נעילה לאוצריא בלבד: יציאה בסיסמה, קוד שחזור חד-פעמי, סוגי קבצים מותרים.
- עברית ואנגלית; "שליחת הערה" דרך מערכת הדיווח של אוצריא.

**דרישות:** אוצריא 0.9.98 ומעלה ו**גשר אוצריא** (OtzariaBridge.exe, בעמוד ה-Releases).
