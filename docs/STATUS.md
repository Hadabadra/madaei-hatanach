# מצב הפרויקט — כלי מערכת לאוצריא (נכון ל-9.10.2026)

שלושה רכיבים: תוסף **הגדרות מערכת**, תוסף **סייר קבצים**, ו**גשר אוצריא** (שירות Windows מקומי).
התוספים מדברים עם הגשר דרך `network.fetchStream` בהרשאת `network.localhost` (ראו [BRIDGE_API.md](BRIDGE_API.md)).

| רכיב | מצב | תיקייה |
|---|---|---|
| הגדרות מערכת | **גמור**, נבדק בדפדפן מול גשר מדומה ומול שרת בדיקה שנכתב לפי החוזה. לא נבדק בתוך אוצריא ולא מול גשר אמיתי | `system-settings/` |
| סייר קבצים | **חלקי**: קיימים manifest, עיצוב, `ui.js`, `util.js`, `icons.js`, `bridge.js`, `fallback.js`. חסרים `index.html`, `js/app.js` | `file-explorer/` |
| גשר אוצריא | **לא נכתב.** קיים רק החוזה המלא | `docs/BRIDGE_API.md` |

> תוכנית העבודה המעודכנת והחסכונית: [WORKPLAN.md](WORKPLAN.md)

## מה הוחלט
- שני תוספים וגשר אחד משותף (הרשאות נפרדות, קהלים שונים). חיפוש קבצים הוא חלק מהסייר.
- גשר: C# / .NET 8, WinForms (מגש) + Kestrel על `127.0.0.1:47917-47921`, קובץ exe יחיד, הפעלה אוטומטית דרך `HKCU Run`.
- נעילה (קיוסק) נשמרת ונאכפת בגשר, כולל סיסמה (PBKDF2), קוד שחזור, והשהיה אחרי 5 ניסיונות. סיסמה ביציאה אינה קשורה למצב סייפר של אוצריא, כי הקוד של אוצריא חוסם מתוספים את מפתחות `key-protected-mode-*`.
- הנעילה הקפדנית (החלפת המעטפת של Windows) מסוכנת בלי בדיקה על מחשב אמיתי. מומלץ להשאיר אותה כבויה בגרסה הראשונה.
- הצעה לשינוי שם בממשק: להציג את מצב הנעילה כ"מצב תורני". ההגדרות עצמן נשארות בתוך אוצריא כי אי אפשר לצאת ל-Windows כשהמחשב נעול.

## מה נשאר לעשות (לפי סדר עדיפות)
1. **גשר אוצריא** לפי `BRIDGE_API.md`: שרת HTTP עם בדיקת כותרת `X-Otzaria-Bridge` וחסימת `Origin`, שירותי קבצים/חיפוש זורם (NDJSON)/לוח/שמע/בהירות/רדיו/בלוטות'/Wi-Fi/הפעלה, נעילה, מתקין, מגש. נדרש קומפילציה ב-CI (`windows-latest`), כי בסביבה שבה נכתב הקוד אין Windows.
2. **סייר קבצים:** מצב גשר מלא (עיון, העתק/גזור/הדבק, מחיקה לסל, שינוי שם, תצוגה מקדימה, חיפוש זורם) ומצב חלופי בלי גשר לתיקיות מאושרות (`fs.pickUserFolder` / `fs.listUserFolder`).
3. בדיקה אמיתית ב-Windows ובאוצריא, ואז פרסום לחנות (ראו הערה למטה).
4. תיאום עם יאיר דניאל: תוסף שתלוי בתוכנה חיצונית, והגשר מופץ בנפרד מהחבילה (`.otzplugin`).

## הערות
- הפרסום לחנות דורש את סודות החנות (`OTZARIA_USER`, `OTZARIA_PASSWORD`) שנמצאים בריפו הזה, וגם workflow. לא נוצר workflow בענף הזה, ולא פורסם דבר.
- בתוסף ההגדרות הנחתי ש-`network.fetchStream` מחזיר את גוף התשובה גם בקודי שגיאה (401/500). לא אומת.
- בקבצי JS אין להשתמש בגרש ASCII בודד בהערות (תוקע את הוולידטור של החנות).
- צילומי המסך לחנות של הגדרות מערכת: `system-settings-screenshots/`.
