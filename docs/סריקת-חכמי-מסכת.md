# סריקת חכמי מסכת — איך עושים את זה למסכת הבאה

נבנה למסכת ערכין (6.2.0, נובמבר 2026). שלושה סקריפטים ב-`_עבודה/scripts/`, שכולם רצים שוב בלי ליצור כפילויות.
המקורות **רק מספריית אוצריא** (`Sivan22/otzaria-library`, תיקיית `אוצריא/`):

* הטקסט: `אוצריא/תלמוד בבלי/סדר <סדר>/<מסכת>.txt` (כותרות `<h2>דף …</h2>`)
* תולדות החכמים: `אוצריא/ספרות עזר/תולדות עם ישראל/סדר הדורות.txt`, חלק `<h2>סדר תנאים ואמוראים</h2>` (ערך = `<b>שם</b>`)

הורדה חסכונית (רק שני הקבצים):

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --no-checkout https://github.com/Sivan22/otzaria-library lib
cd lib && git sparse-checkout set --no-cone "אוצריא/ספרות עזר/תולדות עם ישראל/סדר הדורות.txt" "אוצריא/תלמוד בבלי/סדר <סדר>/<מסכת>.txt" && git checkout
```

## הסקריפטים

| סקריפט | מה עושה | למסכת אחרת |
|---|---|---|
| `arachin-sages-scan-62.js <מסכת.txt>` | סורק את הטקסט מול שמות וכינויי מדריך ״אנשים מהתלמוד״ (התאמה ארוכה, ראשי תיבות, סינון שמות דו-משמעיים). שם שיש לו שני ערכים במדריך נרשם `DUP:<צורה>`. `EXTRA_FORMS=<json>` מוסיף צורות (כותרות סדר הדורות) | כללי — עובד כמות שהוא. כללי הסינון בראש הקובץ (BLOCK_FORMS, NEED_CTX, ABBR) לבדוק מול ההקשרים של המסכת |
| `arachin-sages-add-62.js <סדר הדורות.txt> <מסכת.txt> [שם המסכת]` | חכמים שבמסכת שאין להם ערך במדריך — ערך חדש מסדר הדורות (תחילת הערך + ציון המקור), מראי מקום מהמסכת. ערכי ספק (DOUBT), מיפוי צורות (MAP), כינויים לערכים קיימים (EXISTING_ALIASES) | להעביר שם מסכת כארגומנט שלישי (ברירת מחדל ערכין; הערכים מסומנים `src: sages-<מסכת>`). **לעבור על הפלט** ולעדכן PERSON_SKIP (כותרות שאינן חכמים, זיהוי שגוי), וטבלאות הקטגוריה (TANNA/EARLY/MID/LATE — מי שלא בטבלה נכנס ל״חכמים נוספים״) |
| `arachin-sages-62.js <מסכת.txt>` | בונה את ההקשר ״חכמי המסכת״ במדריך המסכת (`dafs`, קישור לערך המלא, הערת ספק לכינוי סתמי ול-DUP) | להעתיק בשם המסכת ולשנות את `AF` (קובץ המדריך) ואת `masechet`/`'ערכין'` |

סדר הרצה: `add` ← `sages` (ה-add מריץ את הסורק בעצמו).

## כללים שנקבעו (נובמבר 2026)

* לא מנחשים זיהוי. כינוי סתמי (״רבי אלעזר״) — ערך ספק עם לשון המקורות; שם עם שני ערכים (רבי יהודה בן בתירא) — הערת ספק,
  לא בחירה. מה שלא אומת — כתוב ״לא אומת״.
* שני חכמים שסדר הדורות מפריד ביניהם — נשארים שניים (רבי זירא / רב זעירא; מר עוקבא / ר׳ עוקבא).
* כינוי לערך קיים — רק כשהמקור כתוב (בערך עצמו או בסדר הדורות).
* דור ומקום לערכים החדשים — ריקים עד שיימצא מקור שאפשר לשלוף ממנו.
* הביוגרפיה המובנית של אוצריא (`tools.biographies`) וכפתור תוסף ״ביוגרפיות״ מופיעים בכל כרטיס חכם אוטומטית — אין מה להוסיף.
