# קו העיצוב 5.2 — "מודרני מקצה לקצה"

נבנה 21/10/2026 בעקבות משוב משתמש בפורום אוצריא (מראה מרובע, כפתורי אימוג׳י של ווינדוס, חלונות קופצים ישנים). ענף: `work/design-5.2`. נבנה מעל קו 5.1 (`docs/עיצוב-5.1.md`), לא במקומו.

## איפה זה יושב
- **`shell/ui-modern.js`** (נטען מיד אחרי `core.js`):
  - `uiAlert / uiConfirm / uiPrompt` — חלונות דו-שיח מעוצבים, מחזירים Promise, בתור (אחד בכל פעם). `window.alert` מוחלף גלובלית (לא חוסם — בכל המקומות ההודעה היא הפעולה האחרונה).
  - כל `window.confirm` / `window.prompt` בקוד הוסבו ל-`await uiConfirm/uiPrompt` (הפונקציות העוטפות הפכו ל-async). **בקוד חדש — לא להשתמש ב-confirm/prompt של הדפדפן.**
  - אייקונים: מפת אימוג׳י→SVG קווי (`E` ו-`P` בקובץ). המרה על ה-DOM ב-MutationObserver, רק בתוך כפתורים/קישורים/לשוניות/כותרות (`SCOPE`), לא בטקסט רץ ולא בשדות קלט (`SKIP`). כדי להחריג אזור — class `no-icons`. אימוג׳י חדש בכפתור שאין לו מיפוי יישאר אימוג׳י: להוסיף ל-`E`.
- **`shell/router.css` — בלוק "5.2.0"** בסוף הקובץ: כרטיסים `--radius-lg` עם `--elev-1`/`--elev-3`, אייקון כרטיס במשבצת `--primary-soft`, `.panel-btn` מלא ב-primary, עיצוב `.ui-dlg*`. ביטול הקו = מחיקת הבלוק + שורת הסקריפט ב-`index.html`.

## לא בוצע (להמשך)
- לא נבדק בתוך אוצריא בערכה כהה; הצבעים נגזרים מטוקנים ולכן אמורים להתאים.
- מחרוזות האנגלית (`i18n-en.js`) מקבלות את האייקונים דרך אותה המרה.
