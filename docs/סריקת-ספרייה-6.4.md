# סבב 6.4.0 — ייבוא ״ביוגרפיות״ וסריקת הספרייה (16/11/2026)

(הסקריפטים נושאים סיומת ״-63״ — כך נכתבו לפני ש-6.3.0 שוחררה בשיחה אחרת; הגרסה בפועל 6.4.0.)

כל העבודה בסקריפטים שב-`_עבודה/scripts/` (כולם רצים שוב בלי כפילויות). המקורות **רק מספריית אוצריא**
(`Sivan22/otzaria-library`) ומתוסף ״ביוגרפיות״ של יאיר דניאל (`YairDaniel11/otzaria-biographies-plugin`, באישורו).

## הורדה חסכונית

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --no-checkout https://github.com/Sivan22/otzaria-library lib
# רשימת הקבצים: הטקסטים עצמם בלבד (בלי מפרשים) — בבלי/ירושלמי/משנה: אוצריא/<תחום>/סדר */<מסכת>.txt;
# מדרשי חז״ל: אוצריא/מדרש/** בלי מפרשים, הערות, לקח טוב, ילקוט, עין יעקב, בראשית רבתי, שכל טוב, ספר הישר, אוצר מדרשים;
# + אוצריא/ספרות עזר/תולדות עם ישראל/סדר הדורות.txt   (212 קבצים, ~540MB)
cd lib && git sparse-checkout set --no-cone --stdin < lib-files.txt && git checkout
git clone --depth 1 https://github.com/YairDaniel11/otzaria-biographies-plugin
```

⚠️ **אל תריצו `git ls-tree -l` על קלון `blob:none`** — הוא מוריד כל קובץ כדי לדעת את גודלו.

|---|---|

| `bio-import-63.js <…/src/data>` | כל שמות ״ביוגרפיות״ (`bio-data.js` + `bio-enrich.js`, נקראים כ-JSON, לא מריצים את הקוד) → ערך חדש לכל שם שאין לו ערך (שם/כינוי). הפניות (״ע״ע X״, ״הוא X.״ קצר) נעשות כינוי של X. דור — רק ״בדור ה…״ מפורש (לא ״נראה ש…״, לא טווח) או שדה `dor`; מקום — שדה `place` או ״אמורא בבלי/ארץ ישראלי״ בפתיחה. קרדיט בסוף כל תיאור. `src: biographies-63` |
| `library-sages-scan-63.js <אוצריא> <list>` | כותרות ״סדר הדורות״ (סדר תנאים ואמוראים) שנזכרות בהקשר של מימרא בטקסטים ואין להן ערך → ערך מסדר הדורות + שני ציטוטים (`--min=3` מקומות שונים לפחות). שם קרוב בכתיב לשם קיים — לא נוסף, נרשם ב-`_עבודה/out/library-sages-63-fuzzy.txt`. `src: library-63` |
| `bio-midrash-63.js <אוצריא> <list>` | לערכי ״ביוגרפיות״ — עד שני מראי מקום עם ציטוט, רק לשם של שתי מילים לפחות, בלי מספור ״(n)״, בהקשר מימרא, בהתאמה הארוכה ביותר |
| `library-items-scan-63.js <אוצריא> <list>` | מקומות/צומח/דומם/בעלי חיים עם פחות משני מקורות חז״ל — עד שני ציטוטים מספרים שונים. מילה אחת: מסומן ״לא אומת״; מקום — רק אחרי ״איש/עיר/ארץ/הר/כפר/נהר״; דומם במילה אחת — לא נוסף (מילים כלליות). דוח: `_עבודה/out/library-items-63.tsv` |

מראי המקום נבנים ב-`lib-ref-63.js` בצורה ש-`shell/refs.js` פותח (בבלי ``בבלי, X דף ע"א``, ``ירושלמי X פרק, הלכה``, ``משנה, X פרק, משנה``, ``X רבה, פרשה Y``, ``X, פרק Y``).
תנחומא (סימן), מדרש תהילים (מזמור), פסיקתא דרב כהנא (פסקה), מדרש אגדה ומדרש שמואל — מוצגים אבל עוד לא נפתחים בלחיצה (~240 מראי מקום, `tools/validation-report.md` סעיף 5).

## תוצאות

* **אנשים מהתלמוד: 207 → 3,483 ערכים.** 3,238 מ״ביוגרפיות״ (308 הפניות נעשו כינויים, 57 מהם לערכים שהיו), 38 מסדר הדורות (סריקת הספרייה).
  1,129 מערכי ״ביוגרפיות״ קיבלו מראי מקום עם ציטוט (1,629). השאר — בלי `midrash`: שם משותף לכמה חכמים (״אבא (7)״), שם בן מילה אחת, או שלא נמצא בהקשר מימרא.
* **מקומות/צומח/דומם/בעלי חיים:** 510 מקורות חדשים עם ציטוט (מקומות 254, צומח 160, בעלי חיים 59, דומם 37); 270 מסומנים ״לא אומת״.
  נשארו בלי מקור חז״ל: מקומות 171, דומם 316, בעלי חיים 15, צומח 10 (ברשימה שבדוח).
* **פריטים חדשים שאינם במדריכים — לא נוספו אוטומטית:** אין רשימת מועמדים בספרייה שאפשר לסרוק מולה בלי ניחוש. נשאר ב-ROADMAP.
