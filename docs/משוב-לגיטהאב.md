# דרישה קבועה: משוב נשלח גם ל-GitHub

כל משוב/הערה/דיווח תקלה מהתוסף נשלח **בשני ערוצים**:
1. `feedback.report` של אוצריא (כמו תמיד).
2. issue ציבורי בגיטהאב של הריפו של התוסף — משוב ידני עם התווית `user-feedback`, תקלות אוטומטיות עם `auto-report`. פרטים אישיים (שם משתמש בנתיבים, שמות קבצים) מוסתרים.

**איך:** דרך המתווך `https://achat-relay.e0548433917.workers.dev` (Cloudflare Worker, קוד ב-achat-shaalti/tools/relay). הטוקן נמצא רק במתווך — אסור טוקן בתוך תוסף.
- תוסף שמחובר לגשר "אחת שאלתי": `bridge.call('/sys/feedback', { text, plugin, version, repo })`.
- תוסף בלי גשר: `fetch` ישיר למתווך (הכתובת ב-`network.allowlist`), גוף: `{ title, body, fingerprint (16 hex), version (X.Y.Z), kind:"manual", plugin, repo }`.
- ריפו חדש חייב להתווסף למשתנה `GH_REPOS` במתווך, והטוקן צריך Issues: write עליו.

תוסף חדש או גרסה חדשה — חובה לשמור על זה.

> בעינים למקרא זה מומש דרך ממסר Apps Script משלו (shell/personal.js, postReportToRelay) — לא דרך המתווך.
