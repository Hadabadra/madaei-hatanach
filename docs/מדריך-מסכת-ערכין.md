# מדריך מסכת ערכין — 6.0.0 (סבב 6ב, 11/11/2026)

נבנה לקראת מסכת ערכין בדף היומי (מתחילה בט׳ בכסלו תשפ״ז — 19/11/2026).

## הרעיון: מדריך מסכת = קישורים, לא שכפול

כל פריט שבמסכת נכנס **קודם למדריך המתאים** (כלי שיר → דומם/כלי נגינה; מידות קרקע →
דומם/מידות אורך ושטח; ערים → מקומות). מדריך ״ערכין״ עצמו מחזיק ״ערכי קישור״: תקציר קצר
לפי הסוגיה, דף, הקשר, ומראי מקום — וכפתור **״לערך המלא״** שפותח את הערך במדריך שלו.
כך מסכת הבאה היא קובץ נתונים אחד של קישורים, בלי קוד חדש.

### שדות של ערך במדריך מסכת (`guides/arachin/data/arachin-data.js`)

| שדה | מה |
|---|---|
| `name`, `cat`, `explanation`, `makorot`, `note` | כמו בשאר המדריכים. `cat` = ההקשר (ערכי אדם / שיר המקדש / שדה אחוזה ומידות / בתי ערי חומה) |
| `masechet` | שם המסכת כפי שהוא ב-`BAVLI_MASECHTOT` (shell/refs.js) |
| `daf` | `"יג."` / `"יג:"` — מוצג בכרטיס, משמש לשורת הסינון ״דף״ ולשער הבבלי |
| `link: { cat, entry }` | הערך המלא — `cat` הוא מזהה מדריך (`domem`, `places`…), `entry` שם הערך בדיוק |
| `erechTable` / `sadehBox` | תיבות חישוב מיוחדות לערכין (shell/arachin.js) |

הקטגוריה רשומה ב-`CATEGORIES` (shell/core.js) עם `noIdentify: true` — היא לא נכנסת לזיהוי
בטקסט, כי השמות שלה הם ערכים של מדריכים אחרים והזיהוי כבר מוצא אותם שם.

### מה נוסף בתשתית (משרת כל מסכת הבאה)

* **שורות סינון ״דף״ ו״מאפיין״** (shell/guides.js, `GUIDE_ATTR_ROWS`) — מופיעות לבד כשיש
  במדריך ערכים עם `daf` / `tags`. במקומות ״מאפיין״ כולל גם עיר מקלט, עיר לוים ונקודת גבול.
  הסינון נשמר עם שאר הסינון האחרון של המדריך, והמפה מכבדת אותו (= שכבת ״מוקף חומה״ על המפה).
* **שער הבבלי** (shell/shas.js `entriesForBavliDaf`) — מסכת + דף מציגים גם ערכים לפי
  `masechet`+`daf`, ולא רק לפי מראי המקום.
* **בתוך הספרייה** — כפתור ״עינים למקרא״ בסרגל הקורא מזהה את המיקום הפתוח; כשפתוח דף גמרא
  (״ערכין דף יג:״) מוצגים בראש התוצאות הערכים שמראה המקום שלהם הוא הדף
  (`dafMatchesForTitle`, shell/arachin.js), בלי הדגשה בטקסט.
* **מפרשי הבבלי במראי מקום** — `רש"י על ערכין לב.` / `תוספות על חולין נב ע"א` נפרסים
  לספר ״רש"י על ערכין״, דף לב (shell/refs.js).
* **מידות שטח** — `בית סאה`, `בית כור` (shell/measures.js), במ״ר ובדונם לשתי השיטות.
* **#173 — פתיחה מתוסף אחר:**
  ```js
  Otzaria.call('plugin.openOther', { pluginId: 'com.chadbedera.madaeihatanach',
    param: { section: 'arachin', daf: 'יג:' } })          // מדריך ערכין מסונן לדף
  param: { section: 'walled-cities' }                       // מקומות, מסונן ל״מוקף חומה מימות יהושע״
  param: { section: 'domem', entry: 'בית כור' }             // ערך ישיר (קיים מ-5.3.0)
  ```

### מה מסומן ״לא אומת״

* הזיהוי המודרני של גוש חלב (ג׳ש), יודפת (תל יודפת) וגמלא (החורבה ברמת הגולן) — מקובל
  במחקר, לא נמצא בספרי הספרייה. גדוד — אין זיהוי ואין סמן. קצרה — ״עיר קטנה שמחוץ לציפורי״
  (רש״י), הסמן בקירוב במקום ציפורי.
* במגרפה: זיהוי עם אורגן מים — לא אומת (וגמרא שם: ״הרדולים לא היה במקדש״).
* השיעורים (אמה 48 / 57.6 ס״מ, משקל הסלע) — לפי שתי השיטות שכבר בתוסף; לא הוראה למעשה.

## מה נשאר

* **בדיקה באוצריא עצמה** — לא נבדק על מכשיר (אין אוצריא בסביבת הבנייה): פורמט הכותרת של
  דף גמרא בקורא (`loc.title`) הונח גמיש; אם הוא שונה — לעדכן את `dafMatchesForTitle`.
* תמונות לכנור הקיים, למצלתים ולמגרפה — לא נמצאו תמונות מתאימות ברישיון חופשי בסבב הזה.

## להוספת המסכת הבאה

1. לכל פריט חדש — ערך במדריך המתאים (דומם/מקומות/בית המקדש…), עם מראי מקום מהספרייה.
2. `guides/<id>/data/<id>-data.js` עם `CATS` (ההקשרים) ו-`DATA` של ערכי קישור (`masechet`, `daf`, `link`).
   הכי קל: להעתיק את `_עבודה/scripts/arachin-6b.js` ולהחליף תוכן.
3. `_loader.html` (מועתק מ-arachin), שורה ב-`CATEGORIES` (`noIdentify: true`) וב-`CAT_ICON_IMG`,
   שורה ב-`MASECHET_TOOLS` (shell/talmud.js), שדות ב-`GUIDE_FIELDS` (entry-detail.js), ומזהה ב-`OPEN_SECTIONS` (bridge.js).
