# מדריך מסכת ערכין — 6.0.0 (סבב 6ב, 11/11/2026), 6.1.0, 6.2.0 (12/11/2026)

נבנה לקראת מסכת ערכין בדף היומי (מתחילה בט׳ בכסלו תשפ״ז — 19/11/2026).

## הרעיון: מדריך מסכת = קישורים, לא שכפול

כל פריט שבמסכת נכנס **קודם למדריך המתאים** (כלי שיר → דומם/כלי נגינה; מידות קרקע →
דומם/מידות אורך ושטח; ערים → מקומות). מדריך ״ערכין״ עצמו מחזיק ״ערכי קישור״: תקציר קצר
לפי הסוגיה, דף, הקשר, ומראי מקום — וכפתור **״לערך המלא״** שפותח את הערך במדריך שלו.
כך מסכת הבאה היא קובץ נתונים אחד של קישורים, בלי קוד חדש.

### שדות של ערך במדריך מסכת (`guides/arachin/data/arachin-data.js`)

| שדה | מה |
|---|---|
| `name`, `cat`, `explanation`, `makorot`, `note` | כמו בשאר המדריכים. `cat` = ההקשר (ערכי אדם / שיר המקדש / שדה אחוזה ומידות / בתי ערי חומה) |
| `masechet` | שם המסכת כפי שהוא ב-`BAVLI_MASECHTOT` (shell/refs.js) |
| `daf` | `"יג."` / `"יג:"` — מוצג בכרטיס, משמש לשורת הסינון ״דף״ ולשער הבבלי |
| `link: { cat, entry }` | הערך המלא — `cat` הוא מזהה מדריך (`domem`, `places`…), `entry` שם הערך בדיוק |
| `erechTable` / `sadehBox` | תיבות חישוב מיוחדות לערכין (shell/arachin.js) |

הקטגוריה רשומה ב-`CATEGORIES` (shell/core.js) עם `noIdentify: true` — היא לא נכנסת לזיהוי
בטקסט, כי השמות שלה הם ערכים של מדריכים אחרים והזיהוי כבר מוצא אותם שם.

### מה נוסף בתשתית (משרת כל מסכת הבאה)

* **שורות סינון ״דף״ ו״מאפיין״** (shell/guides.js, `GUIDE_ATTR_ROWS`) — מופיעות לבד כשיש
  במדריך ערכים עם `daf` / `tags`. במקומות ״מאפיין״ כולל גם עיר מקלט, עיר לוים ונקודת גבול.
  הסינון נשמר עם שאר הסינון האחרון של המדריך, והמפה מכבדת אותו (= שכבת ״מוקף חומה״ על המפה).
* **שער הבבלי** (shell/shas.js `entriesForBavliDaf`) — מסכת + דף מציגים גם ערכים לפי
  `masechet`+`daf`, ולא רק לפי מראי המקום.
* **בתוך הספרייה** — כפתור ״עינים למקרא״ בסרגל הקורא מזהה את המיקום הפתוח; כשפתוח דף גמרא
  (״ערכין דף יג:״) מוצגים בראש התוצאות הערכים שמראה המקום שלהם הוא הדף
  (`dafMatchesForTitle`, shell/arachin.js), בלי הדגשה בטקסט.
* **מפרשי הבבלי במראי מקום** — `רש"י על ערכין לב.` / `תוספות על חולין נב ע"א` נפרסים
  לספר ״רש"י על ערכין״, דף לב (shell/refs.js).
* **מידות שטח** — `בית סאה`, `בית כור` (shell/measures.js), במ״ר ובדונם לשתי השיטות.
* **#173 — פתיחה מתוסף אחר:**
  ```js
  Otzaria.call('plugin.openOther', { pluginId: 'com.chadbedera.madaeihatanach',
    param: { section: 'arachin', daf: 'יג:' } })          // מדריך ערכין מסונן לדף
  param: { section: 'walled-cities' }                       // מקומות, מסונן ל״מוקף חומה מימות יהושע״
  param: { section: 'domem', entry: 'בית כור' }             // ערך ישיר (קיים מ-5.3.0)
  ```

### מה מסומן ״לא אומת״

* הזיהוי המודרני של גוש חלב (ג׳ש), יודפת (תל יודפת) וגמלא (החורבה ברמת הגולן) — מקובל
  במחקר, לא נמצא בספרי הספרייה. גדוד — אין זיהוי ואין סמן. קצרה — ״עיר קטנה שמחוץ לציפורי״
  (רש״י), הסמן בקירוב במקום ציפורי.
* במגרפה: זיהוי עם אורגן מים — לא אומת (וגמרא שם: ״הרדולים לא היה במקדש״).
* השיעורים (אמה 48 / 57.6 ס״מ, משקל הסלע) — לפי שתי השיטות שכבר בתוסף; לא הוראה למעשה.

## 6.1.0 — המשך (12/11/2026)

* **כרטיס מקושר = הכרטיס המלא.** ערך במדריך מסכת עם `link` נפתח ישר כערך היעד עצמו (אותו אובייקט מ-`dataCache`,
  עם התמונות, השדות והמקורות של המדריך שלו), ומעליו שורת הקשר: מסכת, דף, הקשר, וכפתור ״במדריך X ›״. שום טקסט לא משוכפל.
  העריכה (✏️) מוסתרת שם — עורכים במדריך עצמו. יעד שלא נמצא — התקציר, כמו קודם. (`LINKED_FROM`, shell/arachin.js)
* **תוסף ״בית המקדש״** (מודל תלת-ממדי מאוחד של בית ראשון ובית שני, `com.beit-hamikdash.rishon-3d-model`, yoniny/beit-rishon).
  התוסף מקבל ב-`plugin.page_opened` מיקום קריאה — `{ bookId, currentRef }` — ובוחר את הבית לפי הספר (מלכים א = 10,
  דברי הימים ב = 39 → בית ראשון; משנה מידות = 89 → בית שני) ואת המקום לפי הפרק והפסוק/המשנה. בצד שלנו:
  `templeSpotsOf(entry, catId)` (shell/otzaria-sdk-998.js) — שדה `templeRefs` בערך, ובמדריך בית המקדש מראה המקום
  הראשון של כל בית מהפסוקים/המקורות; כפתור ״🏛 בית ראשון/בית שני — בתוסף בית המקדש ↗״ בכרטיס, וכפתור בסרגל המדריך
  (בלי param — מסך הבחירה של התוסף). לא מותקן — הודעה.
  * ״שנים עשר לויים על הדוכן״: `templeRefs` = דברי הימים ב ה, יב (״עמדים מזרח למזבח״ — בית ראשון) ומשנה מדות ב, ו
    (״והדוכן נתון עליה״ — בית שני). שני המקורות נוספו לכרטיס מהספרייה.
  * **לא אומת על מכשיר:** שהתוסף מתמקד בדיוק במקום (הניתוב לפי הספר והפסוק נקרא מהקוד שלו, גרסה 2.0.4).
* **חלון ״מה חדש״** בפתיחה הראשונה אחרי עדכון (`maybeShowWhatsNewPopup`, shell/personal.js): בלוקי היומן שבין הגרסה
  השמורה (`mh.lastRunVersion`) לנוכחית; מדריך חדש בטווח (`NEW_GUIDE_HIGHLIGHTS`) מודגש בראש עם כפתור פתיחה. התקנה
  חדשה — אין חלון. משתמש ותיק בלי גרסה שמורה — מ-6.0.0.
* **הגדרה ״הסינון סגור בכניסה למדריך״** (`filtersClosed`), ושורות ״דף״/״מאפיין״ בעיצוב הצ׳יפים של שאר השורות (`.attr-chips`).
* **סריקה מלאה** (`_עבודה/scripts/arachin-scan-61.js` ← בחירה ידנית ← `_עבודה/scripts/arachin-61.js`): כל שמות
  הערכים של מקומות, בעלי חיים, צומח, דומם ואישים מול בבלי ערכין שבספרייה; נשארו רק מופעים אמיתיים (בלי מילים נפוצות
  כמו ״אלא״, ״עלי״, ״שום״). 61 ערכי קישור בארבעה הקשרים חדשים — מקומות במסכת · בעלי חיים וצומח · כלים, בגדי כהונה
  ומידות · אישים במסכת — וכל ציטוט נחתך אוטומטית מהטקסט שבספרייה ונוסף גם לערך במדריך שלו (״בבלי, ערכין <דף>״).
  ערכים חדשים: **אלכסנדריא של מצרים** (י:, הצלצול והמכתשת) ו**חרוב** (יד., ״חרוב המורכב״) — הזיהוי המודרני ״לא אומת״.
  * לא נכנסו: שמות החכמים (נוספו ב-6.2.0, למטה), ומופעים שהם רק ציטוט פסוק בלי עניין (שור, איל).

## 6.2.0 — חכמי המסכת (12/11/2026)

* **הקשר חדש ״חכמי המסכת״** (`chachamim`, ט׳): ערך קישור אחד לכל תנא/אמורא שבבבלי ערכין, עם **כל הדפים** שנזכר בהם
  בשדה חדש `dafs` (והראשון ב-`daf`). `dafs` נקרא בשורת הסינון ״דף״ (`GUIDE_ATTR_ROWS`, shell/guides.js), בשער הבבלי
  ובכפתור הקורא (`entriesForBavliDaf`, shell/shas.js), ובשורת ההקשר שבכרטיס המקושר (״דפים …״, shell/arachin.js).
  הקישור — לערך המלא במדריך ״אנשים מהתלמוד״ (`link: { cat: 'amoraim' }`); ציטוט ראשון מכל דף ב-`makorot`.
* **הסריקה** — `_עבודה/scripts/arachin-sages-scan-62.js` (במקום החיפוש הפשוט של 6.1.0, שספר ״רב הונא״ גם כ״רב״):
  התאמה ארוכה ביותר לפי מילים מול שמות וכינויי המדריך; פתיחת ר׳ / א״ר / ר״מ / ר״ש / רשב״ג / ר״נ / ר״ל / ב״ש / ב״ה
  (ר״א, ר״י, ר״ח — דו-משמעיים, לא נפתחים); אות שימוש בראש מילה (ד/ו/כ/ל/מ/ש — לא ב׳: ״ברבי חנינא״ הוא בנו).
  **סינון ידני של שמות דו-משמעיים** (בראש הסקריפט): ״רבי״ ו״רב״ סתם — רק לפני פועל (״רבי אומר״, ״רב אמר״);
  ״רבה״, ״לוי״, ״שמואל״, ״אמי״ — רק ליד אמר/תני/סבר (לא ״לוי״ השבט, לא ״רבה״ התואר); שם חלקי שאחריו בר/בן/בריה
  או לפניו בן/בר/ברבי/חתניה — נדחה (השם המלא אינו במדריך); ״רבן שמעון״ (כינוי שגוי לרשב״י), ״גמליאל״ סתם,
  ״נחמני״, ״חנן״ — לא נספרים; ״רבי יהודה בן בתירא״ — שני ערכים בשם זהה, לא מקושר.
  תוצאה: 72 חכמים, 398 זוגות חכם-דף. ריצה חוזרת של `arachin-sages-62.js` בונה את ההקשר מחדש.
* **לא אומת:** זיהוי לפי כינוי סתמי (״רבי יהודה״ = בר אלעאי, ״רבי שמעון״ = בן יוחאי, ״רבי אליעזר״ = בן הורקנוס,
  ״רבי יהושע״ = בן חנניה, ״רבי״ = רבי יהודה הנשיא, ״רב יהודה״ = בר יחזקאל) — לפי הכלל המקובל; בערך יש הערה.
  שמות שאינם במדריך אנשים מהתלמוד (רבי אלעזר, רבי אמי, רבי אסי, רב מתנה…) — לא נכנסו (ROADMAP).

## מה נשאר

* **בדיקה באוצריא עצמה** — לא נבדק על מכשיר (אין אוצריא בסביבת הבנייה): פורמט הכותרת של
  דף גמרא בקורא (`loc.title`) הונח גמיש; אם הוא שונה — לעדכן את `dafMatchesForTitle`.
* תמונות לכנור הקיים, למצלתים ולמגרפה — לא נמצאו תמונות מתאימות ברישיון חופשי בסבב הזה.

## להוספת המסכת הבאה

1. לכל פריט חדש — ערך במדריך המתאים (דומם/מקומות/בית המקדש…), עם מראי מקום מהספרייה.
2. `guides/<id>/data/<id>-data.js` עם `CATS` (ההקשרים) ו-`DATA` של ערכי קישור (`masechet`, `daf`, `link`).
   הכי קל: להעתיק את `_עבודה/scripts/arachin-6b.js` ולהחליף תוכן.
3. `_loader.html` (מועתק מ-arachin), שורה ב-`CATEGORIES` (`noIdentify: true`) וב-`CAT_ICON_IMG`,
   שורה ב-`MASECHET_TOOLS` (shell/talmud.js), שדות ב-`GUIDE_FIELDS` (entry-detail.js), ומזהה ב-`OPEN_SECTIONS` (bridge.js).
