## שלב ב׳ — יצירת הממסר ב-Google Apps Script (7 דק׳)

1. היכנס ל-<https://script.google.com> ← **New project**
2. מחק את כל מה שכתוב בעורך והדבק במקומו:

```javascript
const REPO = 'Hadabadra/madaei-hatanach';

function doPost(e) {
  try {
    const body    = JSON.parse((e && e.postData && e.postData.contents) || '{}');
    const title   = String(body.title || '').trim().slice(0, 120);
    const details = String(body.body  || '').slice(0, 6000);

    if (!title) return out({ ok: false, error: 'missing title' });
    if (body.secret !== PropertiesService.getScriptProperties().getProperty('SHARED_SECRET')) {
      return out({ ok: false, error: 'bad secret' });
    }

    const token = PropertiesService.getScriptProperties().getProperty('GH_TOKEN');
    const res = UrlFetchApp.fetch('https://api.github.com/repos/' + REPO + '/issues', {
      method: 'post',
      contentType: 'application/json',
      headers: {
        Authorization: 'Bearer ' + token,
        Accept: 'application/vnd.github+json'
      },
      payload: JSON.stringify({ title: title, body: details }),
      muteHttpExceptions: true
    });

    const code = res.getResponseCode();
    return out({ ok: code === 201, status: code });
  } catch (err) {
    return out({ ok: false, error: String(err) });
  }
}

function out(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. **הכנסת הטוקן — לא בקוד.** גלגל השיניים משמאל (**Project Settings**) ←
   גלול ל-**Script Properties** ← **Add script property**, פעמיים:

| Property | Value |
|---|---|
| `GH_TOKEN` | הטוקן שהעתקת בשלב א׳ |
| `SHARED_SECRET` | מחרוזת שתמציא, למשל `tmnch-2026-x9f4` |

   **Save script properties.**

4. **Deploy** (כפתור כחול מימין למעלה) ← **New deployment** ←
   גלגל שיניים ליד ״Select type״ ← **Web app**. מלא:

| שדה | מה לבחור |
|---|---|
| Description | `tmnch relay v1` |
| **Execute as** | **Me** |
| **Who has access** | **Anyone** |

5. **Deploy** ← גוגל תבקש הרשאה: **Authorize access** ← בחר את החשבון שלך ←
   יופיע מסך אזהרה ״Google hasn't verified this app״ ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.
   *(האזהרה תקינה — זה סקריפט שאתה עצמך כתבת, וגוגל מציגה אותה לכל סקריפט לא־מפורסם.)*
6. **העתק את ה-Web app URL** — נראה כך:
   `https://script.google.com/macros/s/AKfy…/exec`

## שלב ג׳ — בדיקה שזה עובד (2 דק׳)

הרץ ב-Git Bash, אחרי שתחליף את שני המקומות המסומנים:

```bash
curl -L -X POST "<כתובת ה-exec שלך>" \
  -H "Content-Type: text/plain" \
  -d '{"secret":"<הסוד שלך>","title":"בדיקת ממסר","body":"אם אתה רואה את זה בגיטהב — הממסר עובד."}'
```

* **הצלחה:** מוחזר `{"ok":true,"status":201}`, ונפתח Issue חדש בריפו.
  לך ל-<https://github.com/Hadabadra/madaei-hatanach/issues>, ודא שהוא שם, וסגור אותו.
* `{"ok":false,"error":"bad secret"}` — הסוד לא תואם למה שהזנת ב-Script Properties.
* `{"ok":false,"status":401}` — הטוקן שגוי או פג.
* `{"ok":false,"status":403}` — לטוקן אין הרשאת **Issues: Read and write**, או שהוא לא כולל את הריפו הזה.

## הערות למי שיבצע את 4.1

* **חובה לשלוח `Content-Type: text/plain`** ולא `application/json`. שליחת JSON
  מפעילה בקשת preflight של CORS, ו-Apps Script אינו עונה עליה — הבקשה תיכשל.
  גוף הבקשה נשאר מחרוזת JSON; רק הכותרת שונה. **זו הטעות הכי נפוצה כאן.**
* **חובה `redirect: 'follow'`** — Apps Script מחזיר 302 לדומיין `googleusercontent.com`.
* `manifest.json` ← `network.allowlist` צריך לכלול **גם** את
  `https://script.google.com` **וגם** את `https://script.googleusercontent.com`.
* הסוד שבתוסף אינו אבטחה אמיתית (אפשר לחלץ אותו מהחבילה) — הוא רק מונע
  מסורקים אקראיים לפתוח Issues. האבטחה האמיתית היא שהטוקן לעולם אינו בחבילה.
* **מכסת Apps Script:** ~20,000 קריאות `UrlFetchApp` ליום בחשבון חינמי. בלתי־רלוונטי בפועל.

## תחזוקה

* **כשהטוקן פג** — הנפק חדש (שלב א׳), עדכן את `GH_TOKEN` ב-Script Properties.
  **אין צורך לפרוס מחדש ואין צורך בגרסה חדשה של התוסף.**
* **אם שינית את קוד הסקריפט** — **Deploy ← Manage deployments ← עריכה ← Version: New version ← Deploy.**
  אם תיצור *New deployment* במקום זה, תקבל כתובת חדשה והתוסף יפסיק לעבוד.

# ✅ המסלול הנבחר — Google Forms (ו׳ באב)

**זה בדיוק מה שתיאר הבעלים של ״ביוגרפיות״** — ״עולה לדרייב ומשם לגיטהב״.
עכשיו ברור **למה** הוא בנה את זה כך: זה המסלול היחיד ששורד נטפרי.

```
התוסף  ──POST──>  docs.google.com/forms/d/e/<ID>/formResponse   ✅ פתוח בנטפרי
                        │
                        ▼
                  התשובה נכנסת לגיליון
                        │
                        ▼  טריגר Apps Script — רץ על שרתי גוגל
                  GitHub Issue                נטפרי כלל לא בתמונה כאן
```

**התובנה שפותרת הכול:** הטריגר רץ **על שרתי גוגל**, לא ברשת של המשתמש. לכן
`api.github.com` נקרא משם בלי שום קשר לסינון. **הדבר היחיד שחייב לעבור דרך נטפרי
הוא ה-POST לטופס — ו-`docs.google.com` פתוח.**

**יתרונות נוספים:** POST לטופס הוא ״בקשה פשוטה״ (`application/x-www-form-urlencoded`)
ולכן **אין CORS preflight** · הגיליון הוא גיבוי מלא של כל דיווח, גם אם פתיחת ה-Issue
נכשלה · לא צריך סוד משותף, כי אין נקודת קצה שאפשר לתקוף.

## מה שכבר עשית לא הולך לאיבוד

* **הטוקן מגיטהב** — משמש בדיוק אותו דבר.
* **פרויקט ה-Apps Script** — הקוד עובר מ-`doPost` לפונקציית טריגר. אותה קריאה
  ל-`UrlFetchApp` בדיוק.
* **מה שכן משתנה:** אין יותר Deploy כ-Web App, ואין `/exec`. במקומם — טריגר.

## ההקמה — סקריפט שבונה הכול לבד (5 דק׳)

**אין צורך ליצור טופס ידנית.** הסקריפט הבא יוצר את הטופס, את הגיליון, את החיבור
ביניהם ואת הטריגר — ומדפיס בסוף בדיוק את מה שצריך למסור לשיחת 4.1.

1. פתח את פרויקט ה-Apps Script הקיים שלך (או חדש: <https://script.google.com>)
2. **מחק את כל הקוד הישן** (ה-`doPost` וה-`out` כבר לא נחוצים) והדבק את שני אלה:

```javascript
const REPO = 'Hadabadra/madaei-hatanach';
const NL   = String.fromCharCode(10);

/** להריץ פעם אחת בלבד. בונה טופס + גיליון + טריגר, ומדפיס את הפרטים ל-4.1. */
function setupTmnchReporting() {
  const form = FormApp.create('דיווחים — עינים למקרא');
  form.setDescription('טופס אוטומטי לדיווחי באגים מתוסף עינים למקרא. אינו מיועד למילוי ידני.');

  const qKind    = form.addTextItem().setTitle('סוג');
  const qTitle   = form.addTextItem().setTitle('כותרת');
  const qDetails = form.addParagraphTextItem().setTitle('פרטים');
  const qEnv     = form.addTextItem().setTitle('סביבה');

  const ss = SpreadsheetApp.create('דיווחים — עינים למקרא');
  form.setDestination(FormApp.DestinationType.SPREADSHEET, ss.getId());

  ScriptApp.newTrigger('onFormSubmit').forSpreadsheet(ss).onFormSubmit().create();

  const pre = form.createResponse()
    .withItemResponse(qKind.createResponse('SUG'))
    .withItemResponse(qTitle.createResponse('KOTERET'))
    .withItemResponse(qDetails.createResponse('PRATIM'))
    .withItemResponse(qEnv.createResponse('SVIVA'))
    .toPrefilledUrl();

  Logger.log('כתובת השליחה : ' + form.getPublishedUrl().replace('/viewform', '/formResponse'));
  Logger.log('מזהי השדות   : ' + pre);
  Logger.log('הגיליון      : ' + ss.getUrl());
  Logger.log('עריכת הטופס  : ' + form.getEditUrl());
}

/** רץ אוטומטית על כל שליחת טופס — על שרתי גוגל, מחוץ לרשת של המשתמש. */
function onFormSubmit(e) {
  const v       = e.values || [];      // [חותמת זמן, סוג, כותרת, פרטים, סביבה]
  const kind    = v[1] || 'דיווח';
  const title   = String(v[2] || '').trim().slice(0, 120) || 'דיווח מהתוסף';
  const details = String(v[3] || '');
  const env     = String(v[4] || '');

  UrlFetchApp.fetch('https://api.github.com/repos/' + REPO + '/issues', {
    method: 'post',
    contentType: 'application/json',
    headers: {
      Authorization: 'Bearer ' + PropertiesService.getScriptProperties().getProperty('GH_TOKEN'),
      Accept: 'application/vnd.github+json'
    },
    payload: JSON.stringify({
      title: '[' + kind + '] ' + title,
      body: [details, '', '---', '**סוג:** ' + kind, '**סביבה:** ' + env].join(NL)
    }),
    muteHttpExceptions: true
  });
}
```

3. **שמור** (Ctrl+S)
4. **הכנס את הטוקן** — הגדרות הפרויקט ← Script Properties ← `GH_TOKEN` = הטוקן מגיטהב
5. בתפריט הפונקציות למעלה בחר **`setupTmnchReporting`** ← **הפעלה** ←

⚠️ **להריץ את `setupTmnchReporting` פעם אחת בלבד.** כל הרצה נוספת תיצור טופס
וגיליון חדשים ותוסיף עוד טריגר.

### פענוח מזהי השדות

שורת ״מזהי השדות״ תיראה כך:

```

```

כלומר `entry.111111` הוא שדה ״סוג״, `entry.222222` הוא ״כותרת״, וכן הלאה —
הערכים שהושתלו הם השמות בעברית באותיות לועזיות, כדי שיהיה חד-משמעי.

### בדיקה מיידית

```bash
curl -s -X POST "<כתובת השליחה>"   --data-urlencode "entry.111111=בדיקה"   --data-urlencode "entry.222222=בדיקת ממסר"   --data-urlencode "entry.333333=אם זה נפתח כ-Issue — הכול עובד"   --data-urlencode "entry.444444=curl"
```

תוך שניות ספורות אמור להיפתח Issue ב-<https://github.com/Hadabadra/madaei-hatanach/issues>.
**אם לא נפתח** — פתח את הגיליון: אם השורה שם, הבעיה בטריגר או בטוקן;

## מה מוסרים לשיחת 4.1

```
כתובת השליחה: https://docs.google.com/forms/d/e/<FORM_ID>/formResponse
שמות השדות:   entry.XXX=סוג · entry.YYY=כותרת · entry.ZZZ=פרטים · entry.WWW=סביבה
```

## הערות למי שיבצע את 4.1 — גרסת Forms

* השליחה היא `POST` עם `Content-Type: application/x-www-form-urlencoded`
  וגוף `entry.XXX=…&entry.YYY=…`. **בקשה פשוטה — אין preflight.**
* **גוגל לא מחזירה תשובה שניתן לקרוא** (חסום ב-CORS). לכן `mode: 'no-cors'`,
  ו״הצלחה״ = הבקשה לא זרקה חריגה. **המשמעות: ה-outbox חייב להישאר** — פריט
  יימחק ממנו רק אחרי שליחה שלא זרקה, ואם היא זרקה הוא נשאר לניסיון הבא.
* `network.allowlist` צריך `https://docs.google.com` בלבד.
* אין סוד משותף ואין טוקן בחבילה — אין מה לחלץ ממנה.

# ✅ שלב ה׳ — הוספת מסלול Web App (10.8.26), על אותו פרויקט

**5 דקות, בלי טוקן חדש** — `GH_TOKEN` וה-`REPO` כבר יושבים בפרויקט מ״שלב ב׳״
המקורי (הטריגר `onFormSubmit`). מוסיפים פונקציה נוספת **לצד** הקוד הקיים,
לא במקומו.

1. פתח את פרויקט ה-Apps Script הקיים (״דיווחים — עינים למקרא״) ב-<https://script.google.com>
2. **בלי למחוק שום דבר קיים**, הוסף בסוף הקובץ:

```javascript
/** מסלול ב׳ — Web App. נקרא ישירות מהתוסף (fetch רגיל, לא no-cors), ומחזיר
 *  תשובה אמיתית שהתוסף יכול לקרוא. אותו REPO ואותו GH_TOKEN כמו onFormSubmit. */
function doPost(e) {
  try {
    const body    = JSON.parse((e && e.postData && e.postData.contents) || '{}');
    const kind    = String(body.kind || 'דיווח').slice(0, 40);
    const title   = String(body.title || '').trim().slice(0, 120) || 'דיווח מהתוסף';
    const details = String(body.details || '').slice(0, 6000);
    const env     = String(body.env || '');

    const res = UrlFetchApp.fetch('https://api.github.com/repos/' + REPO + '/issues', {
      method: 'post',
      contentType: 'application/json',
      headers: {
        Authorization: 'Bearer ' + PropertiesService.getScriptProperties().getProperty('GH_TOKEN'),
        Accept: 'application/vnd.github+json'
      },
      payload: JSON.stringify({
        title: '[' + kind + '] ' + title,
        body: [details, '', '---', '**סוג:** ' + kind, '**סביבה:** ' + env].join(NL)
      }),
      muteHttpExceptions: true
    });

    const code = res.getResponseCode();
    let issueUrl = null;
    try { issueUrl = JSON.parse(res.getContentText() || '{}').html_url || null; } catch(err) {}

    return ContentService.createTextOutput(JSON.stringify({ success: code === 201, url: issueUrl, status: code }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ success: false, error: String(err) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

3. **שמור** (Ctrl+S)
4. **Deploy** (כפתור כחול מימין למעלה) ← **New deployment** ←
   גלגל שיניים ליד ״Select type״ ← **Web app**. מלא:

| שדה | מה לבחור |
|---|---|
| Description | `web app v1` |
| **Execute as** | **Me** |
| **Who has access** | **Anyone** |

5. **Deploy** ← אם זו הפריסה הראשונה של הפרויקט הזה כ-Web App, גוגל תבקש
   הרשאה: **Authorize access** ← החשבון שלך ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.
6. **העתק את ה-Web app URL** — נראה כך: `https://script.google.com/macros/s/AKfy…/exec`

## בדיקה מיידית

```bash
curl -L -X POST "<כתובת ה-exec שלך>" \
  -H "Content-Type: text/plain" \
  -d '{"kind":"בדיקה","title":"בדיקת Web App","details":"אם אתה רואה את זה בגיטהב — המסלול עובד.","env":"curl"}'
```

**הצלחה:** מוחזר `{"success":true,"url":"https://github.com/...","status":201}`,
ונפתח Issue חדש. `success:false` עם `error` — קרא את ההודעה, היא מדויקת.

## מה מוסרים

```
כתובת ה-Web App: https://script.google.com/macros/s/AKfy…/exec
```

רק שורה אחת — היא נכנסת ל-`REPORT_WEBAPP_URL` ב-`shell/personal.js`. **בלי סוד**:
אותו שיקול כמו ב-Forms — אין טוקן בחבילה, ולכל היותר משתמש זדוני יכול לפתוח
Issues, לא לגנוב כלום.

## הערות חשובות

* **`Content-Type: text/plain` דווקא — לא `application/json`.** Web App של
  Apps Script לא מיישם `doOptions`, ופרילייט אמיתי (שהיה קורה עם
  `application/json`) היה נכשל. `text/plain` הוא "בקשה פשוטה" בלי preflight,
  ו-`doPost` מפרק את הטקסט בעצמו עם `JSON.parse`.
* **חובה `redirect: 'follow'`** (ברירת המחדל של `fetch`) — Apps Script מחזיר
  302 לדומיין `googleusercontent.com`, ושם התשובה בפועל קריאה חזרה (יש
  `Access-Control-Allow-Origin`).
* `manifest.json` ← `network.allowlist` צריך גם `https://script.google.com`
  וגם `https://script.googleusercontent.com`.
* **אם שינית את קוד ה-doPost אחרי הפריסה הראשונה** — Deploy ← Manage
  deployments ← עריכה (✏️) ← Version: **New version** ← Deploy. *New
  deployment* במקום זה ייתן כתובת חדשה, והישנה תפסיק לעבוד.

3. בשדה השם הקלד `tmnch-relay` ← **`Deploy`**
   *(נוצר Worker לדוגמה שלא עושה כלום — זה בסדר, מיד נחליף את הקוד)*
4. **`Edit code`** / **`</> Edit code`** ← בעורך שנפתח **סמן הכול (Ctrl+A) ומחק**, ואז הדבק:

```javascript
const REPO = 'Hadabadra/madaei-hatanach';

export default {
  async fetch(request, env) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Content-Type': 'application/json; charset=utf-8'
    };
    const reply = (obj, status = 200) =>
      new Response(JSON.stringify(obj), { status, headers: cors });

    if (request.method === 'OPTIONS') return new Response(null, { headers: cors });
    if (request.method !== 'POST')    return reply({ ok: false, error: 'POST only' });

    let b = {};
    try { b = await request.json(); } catch (e) { return reply({ ok: false, error: 'bad json' }); }

    if (b.secret !== env.SHARED_SECRET) return reply({ ok: false, error: 'bad secret' });

    const title = String(b.title || '').trim().slice(0, 120);
    if (!title) return reply({ ok: false, error: 'missing title' });

    const r = await fetch('https://api.github.com/repos/' + REPO + '/issues', {
      method: 'POST',
      headers: {
        'Authorization': 'Bearer ' + env.GH_TOKEN,
        'Accept': 'application/vnd.github+json',
        'Content-Type': 'application/json',
        'User-Agent': 'tmnch-relay'
      },
      body: JSON.stringify({ title: title, body: String(b.body || '').slice(0, 6000) })
    });

    return reply({ ok: r.status === 201, status: r.status });
  }
};
```

> ⚠️ **`User-Agent` הוא חובה** — GitHub דוחה בקשות בלעדיו ב-403.

5. **`Deploy`** (ימין למעלה) ← אשר. ואז חזרה למסך ה-Worker (**`←`** או **`Back`**)
