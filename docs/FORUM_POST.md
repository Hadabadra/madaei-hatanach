# טיוטה לפורום אוצריא — נושא "עזרה | מחשב תורני" (2673)

> לא פורסם. לעבור, לתקן ולפרסם ידנית.

---

עדכון: גשר אוצריא + "סייר קבצים" + "הגדרות מערכת" — גרסת בטא לבדיקה

שלום לכולם,

יצאה גרסת בטא ראשונה של שלושת הרכיבים:

1. **גשר אוצריא** (OtzariaBridge.exe) — תוכנה קטנה שרצה ברקע ב-Windows ומאפשרת לתוספים לנהל קבצים ולשלוט בהגדרות המחשב. מאזינה רק למחשב המקומי (127.0.0.1).
2. **סייר קבצים** — עיון, העתקה/גזירה/הדבקה, מחיקה לסל המיחזור, שינוי שם, תיקייה/קובץ חדש, חיפוש זורם (גם בתוכן), תצוגת טקסט ותמונות, וכפתור "+ מסמך חדש" בסרגל הקורא. בלי הגשר עובד במצב מוגבל על תיקיות שאושרו.
3. **הגדרות מערכת** — שמע, בהירות, בלוטות׳, Wi-Fi, הפעלה/כיבוי, ומצב נעילה עם יציאה בסיסמה וקוד שחזור.

שני התוספים תומכים גם באנגלית (מתג בסרגל העליון).

**הורדה:** עמוד ה-Releases של הריפו (תג `bridge-v1.0.0`). שם נמצאים ה-exe ושני קובצי ה-`.otzplugin`.

**מה מבקשים מכם:**
- להריץ על מחשבי Windows אמיתיים (10/11, נייח ונייד) ולדווח מה לא עבד — בעיקר Wi-Fi, החלפת התקן שמע, בלוטות׳ וחסימת מקשים.
- בדיקת אבטחה למצב הנעילה: ניסיונות "לברוח" מהנעילה. **לא להפעיל "נעילה קפדנית" לפני שרושמים את קוד השחזור.**

הפרסום בחנות אוצריא ייעשה רק אחרי הבדיקות האלה.
