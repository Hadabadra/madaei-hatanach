# 5.3.0 — כרטיס בחלונית צד, תצוגה מקדימה, פתיחת ערך מתוסף אחר

## כרטיס ערך בחלונית צד (`shell/side-panel.js`)
* בתוך מדריך, במסך ≥ 900px, הכרטיס נפתח בחלונית בצד שמאל. הרשימה נשארת גלויה.
* לחיצה חוזרת על אותה כרטיסייה סוגרת. יציאה מהמדריך סוגרת. Esc סוגר.
* הסרגל העליון והמסננים נשארים לכל הרוחב: החלונית מתחילה ב-`--side-top`
  (ראש `#guideGrid`), ו-ResizeObserver מעדכן כשהמסננים נפתחים/נסגרים.
* גבול נגרר (`.side-grip`), הרוחב נשמר ב-localStorage (`mh.sideW`).
* שורת ניווט: → ← (וגם מקשי החיצים) לערך הקודם/הבא, 🔗 להעתקת קריאת פתיחה, ✕.
* הגדרה: ״כרטיס ערך בחלונית צד״ (`uiPrefs.entrySide`, ברירת מחדל דלוק). כבוי = החלון הקופץ הישן.
* מלכודת: `#guideView` הוא `position:fixed`, ולכן `offsetParent` שלו תמיד null.
  בודקים `guideView.classList.contains('open')`.

## תצוגה מקדימה בעמוד הבית
* `#homePreview` יושב רק ברווח הפנוי משמאל לכרטיסים (לא דוחס אותם). פחות מ-260px פנויים — לא מוצג.
* קו דק מפריד בינו לבין הכרטיסים. תיאורי המדריכים: `DESC` ב-side-panel.js.

## #173 — פתיחת ערך מסוים מתוסף אחר
```js
Otzaria.call('plugin.openOther', {
  pluginId: 'com.chadbedera.madaeihatanach',
  param: { section: 'places', entry: 'באר שבע' }
})
```
`entry` (חדש ב-5.3.0) פותח את כרטיס הערך בשם הזה בתוך המדריך (השוואה בלי ניקוד).
בלי `entry` — ההתנהגות של 5.2.0 (`section` ו-`term`). כפתור 🔗 בכרטיס מעתיק בדיוק את הקריאה הזו.
